MacTabletMode 1.00.2 release notes

Changes since v1.00.1:

  • KeyboardAvoidanceManager skips FrameBundle windows whose AX parent is another window in the same process
  • Escape on tap, Control on hold” setting.
  • restore any window frames we altered after showing the keyboard, restore dock auto hide and menu bar auto hide settings
  • Reclaim hidden menu-bar space using display geometry
  • Adjust current Space window frames around the soft keyboard
  • key colors
  • Add compact keyboard ribbon aligned flush with the body
  • showmenubar hidemenubar (on keyboard show/hide)
  • modifier remains flagged as pressed if the key combo was not handled natively
  • stop anchoring keyboard above dock (float on top, bottom of screen)
  • Avoid duplicate Dock actions when forwarding Sidecar touches
  • Start keyboard focus listeners without waiting for window discovery
  • Add preferences item to menu bar
  • add ci/cd scripts/make-release.sh
