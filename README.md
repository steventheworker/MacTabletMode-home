# MacTabletMode

An iPad-style soft keyboard for macOS — type by touch in any app

MacTabletMode brings an iPad-style on-screen keyboard to the Mac. It watches the focused input and slides a floating, non-activating keyboard panel into place, nudging the target window out of the way so nothing you type is hidden. Keys inject real keystrokes into whatever app you are using — including on a Sidecar tablet display.
