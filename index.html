MacTabletMode

An iPad-style soft keyboard for macOS — type by touch in any app

MacTabletMode brings an iPad-style on-screen keyboard to the Mac. It watches the focused input and slides a floating, non-activating keyboard panel into place, nudging the target window out of the way so nothing you type is hidden. Keys inject real keystrokes into whatever app you are using — including on a Sidecar tablet display.

Features

  • iPad-style soft keyboard — a full Mac key layout (esc + F-row, modifiers, arrows) that injects real keystrokes into the focused app without stealing focus
  • Auto-reveal — the keyboard appears when a text field gains focus and hides when you dismiss it; turn it off to only open it manually
  • Keyboard avoidance — the target window is nudged out of the way so the field you are typing in stays visible, then restored
  • Full modifier row — shift, control, option, command and fn, with a shift layer for symbols and press-and-hold key repeat
  • Dock aware — keeps the keyboard above a revealed or auto-hidden Dock, with a menu-bar Show Dock action (Fn+A)
  • Touch on Sidecar — forwards iPad touchscreen Dock taps as global clicks for Dock-preview apps, while leaving trackpad clicks alone
  • Mission Control, App Exposé and Show Desktop aware — steps aside for overviews and re-checks the focused input when they close
  • Configurable — a draggable floating toggle button, plus a bottom-right arrow key you can set to down, resend-last, toggle-keyboard, or four arrows
